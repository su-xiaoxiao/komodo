## 维护边界

上游 `main` 保留上游历史，功能在 `integration/local-platform-zh-cn` 分支开发。`upstream` 指向原项目，`origin` 指向 fork。不修改 API 枚举、资源 ID、Compose 字段、Git ref、代码编辑器内容、终端日志或用户数据来实现中文。

中文词典、提取/检查工具和平台适配分别管理。中文缺失时回退英文；英文源文变化时产生待翻译项，不套用旧中文。界面允许切换简体中文/English并保存偏好。

## 上游更新流程

1. `git fetch upstream`，从当前适配分支建立升级分支，合并指定上游 tag/commit；不自动覆盖当前工作区。
2. 重新提取界面文案，输出新增/删除/未翻译清单；更新中文包并审核语义。
3. 运行翻译检查、类型检查、前端构建和页面测试。
4. 在独立 Komodo 实例验证项目导入、镜像来源、构建与回退；保留旧版本及数据备份。
5. 验收后更新基线记录并发布固定版本镜像。

远程 fork 已创建不代表适配改动已提交/推送；以实际分支和提交为准。
