# 中文包与上游更新检查

## 结构

- `../src/localization/zh-CN.json`：以原英文为键的简体中文词典。相同英文可复用翻译，英文变化自动成为新条目。
- `transform.mjs`：只解析界面展示位置的 AST，构建时注入翻译调用，不批量重写上游 TSX。
- `catalog.json`：原英文及来源文件/行号，覆盖主项目 TSX 和锁定版本 mogh_ui 的静态展示文案。
- `retained.json`：明确保留的命令、路径、品牌、协议和单位，不能作为缺译的通用忽略列表。
- `checks.mjs`：缺译、空译文及 `{name}` / `[[$VERSION]]` 占位符检查。
- `reports/coverage.json`：本机生成的新增、移除、失效和缺译报告，不提交。
- `../src/localization/shared-ui.tsx`：为共享组件的动态系统选项卡添加展示标签，保留原 value。

切换语言会刷新当前页面，偏好保存在浏览器 `komodo.locale`。缺少翻译时显示原英文，不隐藏控件。

## 每次更新上游

1. 合并到升级分支，使用锁文件安装主 UI 和客户端依赖。
2. 先运行 `yarn i18n:check`，读取新增/移除/缺译报告；源文变化不会误用旧中文。
3. 运行 `yarn i18n:extract` 更新索引，补译并人工核对失效条目。部分仅供动态系统标签使用的词条可以保留。
4. 运行 `yarn i18n:test && yarn i18n:check && yarn build`。
5. 在独立实例检查中英文登录、导航、项目配置、发布确认、日志和编辑器；用真实项目验证接口参数和回退行为。

CI 工作流 `.github/workflows/downstream-localization.yml` 重复执行检查与构建。不要在 CI 中先执行 extract，否则会掩盖未审阅的索引变更。

## 边界

已覆盖 JSX 静态文字、展示属性、label/title 元数据、模板字符串占位符及 mogh_ui 编译后 JSX 中对应位置。不会翻译 value/name/id、API 枚举、命令执行参数、代码块、终端输出和用户填写的数据。非模板的动态拼接句子、自动从字段名生成的标题、后端错误信息仍需逐项适配，静态覆盖率不是全站汉化率。

上游可能改变组件结构或把静态文案改成动态表达式，因此不能承诺任何版本都免人工修改。新/移除文案检查、固定依赖、单元测试和页面验收共同构成升级流程。

配置对象说明、片段等自动提取暂未覆盖的位置可显式导入 `@/localization/runtime` 的 `t`。提取器识别该导入及别名，将字符串纳入源文变更检查，并避免二次包装；不会把任意同名函数当作翻译调用。2026-09-22 补齐主机连接说明与 Swarm 介绍。

服务器页面另覆盖配置对象的 description/placeholder、表格 header 和 JSX Fragment，并为自动字段标题提供显式 label。此扩展按 resources/server/ 目录限定，不扫描任意 API 对象。历史图表使用不翻译的 key 作为数据与颜色索引，标题/图例/提示单独翻译；监控粒度选项保留原 value，只翻译 label。动态系统词条可能在 stale 中保留，不代表应删除。
